# Numeria · Aventuras matemáticas

Juego educativo (PWA para tablet con lápiz, ordenador y móvil) para aprender las tablas de multiplicar, sumas,
restas, multiplicaciones y divisiones a través de una historia. Pensado para familias y colegios.

- Stack: Vite + React + TypeScript, Supabase (auth + base de datos), desplegado en Vercel.
- Documentación: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/PEDAGOGY.md`](docs/PEDAGOGY.md),
  [`docs/STORY.md`](docs/STORY.md), [`docs/SUPABASE_SETUP.md`](docs/SUPABASE_SETUP.md).

## Desarrollo

```bash
npm install
cp .env.example .env.local   # opcional: sin estas variables la app funciona solo en local
npm run dev
```
