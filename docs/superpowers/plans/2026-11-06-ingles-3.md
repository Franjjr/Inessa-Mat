# Inglés de 3.º — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Inglés becomes the third subject of Repasitos for 3.º. It gets a syllabus, classes, listening, matching and
writing exercises, a number game in English, a word game, its own 10-minute daily session after Lengua, a placement
test and a section in the adult report (milestone A). Then it gets its own island on the map, with stories and
guardians (B). Then it gets optional speaking with Azure pronunciation scoring, enabled by an adult (C).

**Architecture:**
- English skills carry the prefix `eng:` and topics carry `eng-`.
- The two-way `'language'` special cases (`src/engine/subjects.ts`, `src/world/session/logic.ts`,
  `src/content/syllabus/index.ts`, `todayEntry.ts`…) become per-subject tables over `LessonSubject = 'math' |
  'language' | 'english'`. This is done once, in Task 1, so adding English is data rather than another `if`.
- English reuses:
  - the syllabus model, `clase()` five-phase classes, `ExerciseStep` and `GameHost`;
  - the `text` answer type and `LetterKeyboard` for words, and the `number` answer for digits;
  - the shared star wallet.
- English words are said by a new speech character, `english` (an Azure `en-GB` voice through `/api/tts`).
- Pictures are emoji, as the maths lessons already use.
- The island is a standalone world, id `isla-ingles`. It is not a season. Its progress lives in
  `ProgressState.worlds['isla-ingles']` (jsonb, synced, no migration).
- Pronunciation is a new Vercel Function, `/api/pronunciation`, that calls Azure Speech pronunciation assessment on the
  F0 tier.

**Tech Stack:** React 19 + TypeScript, Vite, Dexie, Supabase sync, Vercel Functions, Azure Speech (TTS +
pronunciation assessment, region `northeurope`), Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-06-ingles-3-design.md`

## Global Constraints

- **Explain before practising.** Every topic has a five-phase class before its exercises. The spec says: «que sea
  aburrido o solo ejercicios sin explicar» is the failure.
- **Child-facing language.**
  - Lumi explains in Spanish.
  - English words and phrases are spoken by the `english` character with a British voice (`en-GB`). The owner picks
    the final voice by ear; the default is `en-GB-SoniaNeural`.
  - Spanish text uses the masculine generic and two genders only, with no inclusive language.
- **Hints and content.**
  - Hints never give the answer.
  - Stories and texts are original, never copied from textbooks.
- **Writing answers.** English words are typed with the letter keyboard. Digits are written as in maths (pen or
  keypad).
- **Session and progress.**
  - The English session lasts about 10 minutes (`ENGLISH_SESSION_MINUTES = 10`). «Hoy» offers it after Lengua, or
    after maths when Lengua is off.
  - Maths and Lengua must not change. Their progress, sessions, stars, menu, placement, classes and reports behave as
    before, and existing tests keep passing.
  - Stars, the shop, the album and the chest are shared. The English session gives its stars once a day.
  - Pronunciation stars are shown only at the moment of speaking. They never reach the wallet and never count for
    mastery.
- **Who gets English.** It can be enabled for children of 3.º and children with no course. For 2.º and 4.º it shows as
  «Pronto».
- **Microphone.**
  - It is off by default and only an adult can enable it, with explicit consent.
  - Azure F0 only, never a paid tier: about 5 h per month, shared by all children.
  - At most 10 speaking attempts per child per day.
  - When Azure fails or refuses, the speaking item is skipped without penalty and not retried that day.
  - Audio is processed in `northeurope` and never stored.
- **Server limits.** `error_type` and `kind` ≤ 32 characters; `skill` ≤ 64; TTS text ≤ 400 characters (`MAX_CHARS`).
  Never play audio in tests.
- **Workflow.**
  - Type check with `npx tsc -b`.
  - Work on branch `ingles` (or a worktree from it) and merge into `main` only when the owner says so.
  - Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Layout checks.** For any screen of the child area, verify that the advance button is visible or reachable with «⬇
  Más abajo». Use real touch or `element.click()`, never `page.click()`. Use the short viewports 1366×657, 1000×490 and
  390×844, with `pointer: coarse` emulated via CDP for tablets. See the memory note on scroll reachability.

## Review Focus

1. **A child with all three subjects on.** No English row ever appears in the maths or Lengua warm-up, mix, review,
   «Repasar» count, report or dashboard stats, and the other way round. Covered by Task 1 over the real readers.
2. **«Hoy» order with any subset of subjects on.** With maths, Lengua and English, the order is maths → Lengua →
   English. With maths and English, it is maths → English. With only English, it is English. With maths only, nothing
   changes. Covered by the Task 1 `homeSubject` table test.
3. **Typed English with real-world variation.** «Seven», «seven », «SEVEN», «twenty one» vs «twenty-one», «what’s»
   (curly apostrophe) vs «what's», «grey» vs «gray». The rules are explicit and tested in Task 3.
4. **Device speech fallback when `/api/tts` fails.** An English word must be spoken with an `en-GB` device voice, or an
   English one if none exists. It must never be read by a Spanish voice, and digits must never be turned into Spanish
   words. Covered by Task 2.
5. **Microphone denied, unavailable, or Azure quota exhausted mid-session.** The item is skipped without penalty, the
   session continues, and no error dialog appears. The 11th attempt in a day is never offered. Covered by Task 12.

### Task 3: Words, numbers and how an English answer is checked

**Files:**
- Create:
  - `src/engine/ingles/words.ts`
  - `src/engine/ingles/numbers.ts`
  - `src/engine/ingles/text.ts`

**Interfaces — Produces:**
- `type EnglishTheme = 'saludos' | 'colores' | 'animales' | 'familia' | 'comida' | 'ropa' | 'cole' | 'casa' |
  'cuerpo' | 'tiempo' | 'dias'`.
- `interface EnglishWord { en: string; es: string; emoji?: string; theme: EnglishTheme; alts?: string[] }`.
- `ENGLISH_WORDS: EnglishWord[]`: ≥ 8 per theme. The 3.º vocabulary of the spec table includes «days and months». A
  picture theme needs emoji on every word; `dias` and `saludos` may go without.
- `numberToEnglish(n: number): string` for 0–100: `21 → 'twenty-one'`, `100 → 'one hundred'`, `13 → 'thirteen'`.
- `operationToEnglish(a, op: '+' | '-' | '×', b): string`, for example `'three plus four'`, `'nine minus two'`,
  `'two times five'`.
- `compareEnglish(given: string, expected: string, alts?: string[]): { correct: boolean; nearMiss: boolean }`:
  - case-insensitive;
  - trims and collapses spaces;
  - `’` is the same as `'`;
  - hyphen is the same as a space inside number words;
  - any of `alts` is accepted;
  - `nearMiss` is true when the answer is one edit away (wrong, but the feedback says «¡Casi!»).

- [ ] **Step 1: Write the failing tests.**

  - `compareEnglish('Twenty one', 'twenty-one').correct`.
  - `compareEnglish('what’s', "what's").correct`.
  - `compareEnglish('gray', 'grey', ['gray']).correct`.
  - `compareEnglish('tree', 'three')` is `{ correct: false, nearMiss: true }`.
  - Every word has a unique `en` within its theme.
  - Picture themes have an emoji on every word.
